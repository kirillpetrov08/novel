# Шаблон папки истории

Скопируй эту папку и переименуй в следующий номер: `stores/1/`, `stores/2/`, `stores/3/`…

Внутри папки истории:

```
stores/1/
  story.json      — сюжет (этот шаблон; замени ТЕКСТ ЗАГЛАВНЫМИ на настоящий)
  cover.jpg       — обложка, вертикаль 2:3
  images/
    bg-01.jpg     — фоны сцен, вертикаль 9:16
    hero.png      — персонажи, PNG с прозрачным фоном
```

Пути к картинкам в `story.json` пишутся **относительно папки истории**: `"cover": "cover.jpg"`, `"bg": "images/bg-01.jpg"`. Картинка необязательна: пустая строка или отсутствующий файл → бежевый градиент.

Эта папка `_template` в приложение не попадает (загружаются только номерные папки).
