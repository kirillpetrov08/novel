# Папка историй `stores/`

**Одна история = одна папка: сюжет и фото вместе.** Ты коммитишь папку — при сборке Android-приложения история автоматически вшивается внутрь. Код трогать не нужно.

## Структура

```
stores/
  1/
    story.json      ← сюжет (пути к картинкам внутри — относительные)
    cover.jpg       ← обложка (вертикаль 2:3)
    images/
      bg-01.jpg     ← фоны сцен (вертикаль 9:16)
      hero.png      ← персонажи (PNG, прозрачный фон)
  2/
    story.json
    cover.jpg
    images/
      ...
  _template/        ← шаблон-каркас, в приложение не попадает
```

## Как добавить историю

1. Возьми следующий свободный номер: есть `1/` и `2/` → новая папка `3/`. Номера идут **подряд, без пропусков**.
2. Положи в неё `story.json` и картинки рядом. В `story.json` пути пишутся относительно папки истории: `"cover": "cover.jpg"`, `"bg": "images/bg-01.jpg"`, `"image": "images/hero.png"`.
3. Проверь: `npm run validate` (ловит битые сцены, дубли id, отсутствующие картинки).
4. Закоммить папку. Дальше: пересобери приложение (GitHub Actions соберёт сам при коммите в `main`) и загрузи новый AAB в RuStore как обновление — см. `../RUSTORE.md`.

## Правила

- `id` каждой истории уникален (латиница/цифры/дефис) и **не меняется** после публикации — по нему хранится прогресс игроков.
- Картинка необязательна: нет файла или пустой путь → покажется бежевый градиент / монограмма персонажа.
- Сжимай фото до ~300–500 КБ (сборка предупредит о файлах тяжелее 1,5 МБ) — размер приложения влияет на установки.
- Битый `story.json` остановит сборку с понятной ошибкой на русском — битый релиз в RuStore не уедет.
- Совместимость: старый плоский формат `stores/N.json` тоже подхватывается, но основной — папки.

Формат сюжета: `../STORY_FORMAT.md`. Промпт для ИИ-генератора: `../PROMPT_FOR_AI.md`.
