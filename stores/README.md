# Папка историй `stores/`

 сюда кладутся истории. Приложение подхватывает их **автоматически** при загрузке — код трогать не нужно.

## Как добавить историю

1. Возьми следующий свободный номер: если есть `1.json` и `2.json` — новый файл будет `3.json`.
2. Сохрани JSON истории как `stores/N.json` (номера идут **подряд, без пропусков**: 1, 2, 3, …).
3. Закоммить файл. Готово — история появится в библиотеке.

Один файл может содержать:
- одну историю (объект) — обычный вариант;
- массив историй `[ {...}, {...} ]`;
- объект `{ "stories": [ {...}, {...} ] }`.

## Правила

- `id` каждой истории уникальный, только латиница/цифры/дефис (`"id": "tayna-usadby"`).
- Файл `_template.json` в этой папке — шаблон-каркас, приложение его игнорирует (загружаются только файлы с номерами).
- Битый JSON не ломает приложение: файл пропустится, а причина покажется в библиотеке в блоке «Диагностика загрузки».
- Перед коммитом проверяй файл: `node tools/validate.mjs stores` — проверит всю папку.

## Необязательный манифест

Если номеров станет много или захочется явный список, можно создать `stores/index.json`:

```json
[1, 2, 3]
```

или

```json
{ "count": 3 }
```

Если манифеста нет, приложение само перебирает `1.json, 2.json, 3.json…` до первого отсутствующего номера.

## Картинки

- Обложки: `assets/covers/<id>.jpg` (вертикаль 2:3)
- Фоны сцен: `assets/backgrounds/<id>/bg-01.jpg` (вертикаль 9:16)
- Персонажи: `assets/characters/<id>/<персонаж>.png` (прозрачный фон)

Картинка необязательна: если поле пустое или файл не найден, приложение покажет бежевый градиент и монограмму персонажа — битых картинок не будет.

Полный формат: `../STORY_FORMAT.md`. Промпт для ИИ-генератора: `../PROMPT_FOR_AI.md`.
