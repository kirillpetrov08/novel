# Промпт для ИИ, которая генерирует истории и картинки

## Как пользоваться (для тебя)

1. Скопируй блок ниже целиком и вставь другой ИИ.
2. В начале блока есть 5 полей в `[квадратных скобках]` — заполни те, что хочешь (жанр, тема…). Не заполнишь — ИИ придумает сама. Сюжет в промпте **специально не задан**.
3. ИИ вернёт три части: **(1)** JSON → сохрани его как `stores/N.json` (N — следующий номер: 1, 2, 3…) и закоммить; **(2)** список промптов для картинок → сгенерируй по ним изображения и положи по указанным путям в `assets/`; **(3)** короткий отчёт самопроверки.
4. Перед коммитом проверь файл: `node tools/validate.mjs stores/N.json` — или просто вставь JSON во вкладке «Импорт» в приложении: ошибки покажутся сразу.

## ▼ КОПИРОВАТЬ ОТСЮДА ▼

```text
Ты — сценарист и геймдизайнер интерактивных визуальных новелл в духе «Клуба Романтики».
Твоя задача — ПОЛНОСТЬЮ САМОСТОЯТЕЛЬНО придумать оригинальную историю и оформить её
строго в JSON-формате моего приложения. Сюжет, персонажей, названия и диалоги придумываешь ты.

ПАРАМЕТРЫ ЗАКАЗА (если поле не заполнено — придумай сам):
- Номер файла: [например: 1]  → результат будет сохранён как stores/НОМЕР.json
- Жанр: [например: романтика + мистика / оставь пустым]
- Тема и сеттинг: [например: маленький приморский город, наши дни / оставь пустым]
- Тон и аудитория: [по умолчанию: лёгкая романтика, 16+, без откровенных сцен]
- Длительность: [по умолчанию: 12–20 минут чтения]

============================================================
ЧТО ВЫДАТЬ В ОТВЕТЕ — ровно три части, в этом порядке:
ЧАСТЬ 1. Только JSON истории одним блоком кода ```json ... ``` — без единого слова до него.
ЧАСТЬ 2. Список картинок: таблица «файл | тип | промпт на английском» (правила ниже).
ЧАСТЬ 3. Отчёт самопроверки: 5–8 коротких строк по чек-листу в конце этого задания.
============================================================

--------------- ФОРМАТ JSON (соблюдать точно) ---------------

Корневой объект:
{
  "id": "unikalnyy-id",            // СТРОГО латиница, цифры, дефис. Уникален для каждой истории
  "title": "Название истории",
  "description": "2–3 предложения для карточки в библиотеке: кто героиня, что происходит, интрига. БЕЗ спойлеров финала. До 280 символов",
  "genre": "Романтика · Мистика",
  "author": "AI",
  "cover": "assets/covers/unikalnyy-id.jpg",
  "coverGradient": ["#E9DCC3", "#B49B72"],   // 2 бежево-землистых HEX: фон, если картинки нет
  "coverSymbol": "✦",                       // 1 символ-эмблема обложки
  "tags": ["романтика", "тайна"],
  "estimatedMinutes": 15,
  "start": "s1",                            // id первой сцены
  "stats": { ... },                         // характеристики — см. ниже
  "characters": { ... },                    // персонажи — см. ниже
  "scenes": { ... }                         // все сцены — см. ниже
}

"stats" — шкалы, которые меняют выборы игрока. Придумай 2–3 шкалы под свой сюжет,
например отношения с персонажем, решимость, репутация, улики:
"stats": {
  "hero":  { "label": "Имя персонажа", "icon": "♡" },
  "brave": { "label": "Решимость", "icon": "✦" }
}
Ключи — латиницей. Все шкалы начинаются с 0 и только растут на +1 за выбор.

"characters" — 3–6 персонажей. Героиня обязательна, повествование о ней — от второго лица («ты»):
"characters": {
  "heroine": { "name": "Имя", "color": "#8A6D4B", "image": "" },
  "hero":    { "name": "Имя Фамилия", "color": "#5C6650", "image": "assets/characters/unikalnyy-id/hero.png" }
}
color — приглушённый землистый HEX (бежевый, бронзовый, оливковый, терракотовый, серо-коричневый).
Никаких ярких неоновых цветов. image можно оставить "" — приложение покажет монограмму.

"scenes" — словарь сцен. Именуй так: s1, s2, s3…; ответвления: s4a, s4b; финалы: ending_good, ending_bad и т.п.
Каждая сцена:
{
  "bg": "assets/backgrounds/unikalnyy-id/bg-01.jpg",   // или "" — тогда сработает градиент
  "bgGradient": ["#EFE6D4", "#D8C7A8"],                // ОБЯЗАТЕЛЬНО у каждой сцены: 2 HEX под настроение/время суток (утро — светлее, ночь — темнее)
  "show": ["heroine", "hero"],                         // кто на экране (0–3 персонажа). Только id из characters
  "lines": [ ... ],                                    // реплики — см. ниже
  // дальше РОВНО ОДИН из четырёх вариантов продолжения:
  "choices": [ ... ]        // вариант А: выборы игрока
  "next": "s5"              // вариант Б: линейный переход к сцене
  "branch": [...], "next": "s5"   // вариант В: переход по условию (+ обязательный запасной next)
  "ending": { ... }         // вариант Г: это финал истории
}

Строки "lines" — 2–6 на сцену. Типы:
{ "type": "narration", "text": "Текст от автора: место, действие, атмосфера." }
{ "type": "dialogue", "who": "hero", "text": "Реплика персонажа." }
{ "type": "thought", "who": "heroine", "text": "Внутренняя мысль героини." }

Выборы "choices" — 2–3 варианта:
{ "text": "Короткий текст кнопки", "next": "s4a" }
{ "text": "...", "next": "s4b", "effect": { "brave": 1 } }                                  // +1 к шкале
{ "text": "...", "next": "s4c", "crystals": 12, "effect": { "hero": 1 } }                    // платный выбор
{ "text": "...", "next": "s4d", "crystals": 15, "requires": { "hero": 2 }, "effect": {} }    // платный + нужен уровень шкалы

Переход по условию "branch" (проверяется сверху вниз, первый подошедший выигрывает):
"branch": [
  { "if": { "stat": "hero", "gte": 3 }, "to": "ending_love" },
  { "if": { "stat": "brave", "gte": 2 }, "to": "ending_brave" }
],
"next": "ending_neutral"

Финал "ending":
"ending": { "title": "Название финала", "text": "1–2 предложения итога этой ветки", "badge": "♡ Романтический финал" }

--------------- ЖЁСТКИЕ ОГРАНИЧЕНИЯ ТЕКСТА ---------------
(приложение для телефона: длинный текст физически не влезет в экран)
- Одна строка lines: 1–2 коротких предложения, МАКСИМУМ 220 символов.
- Текст выбора: МАКСИМУМ 60 символов. Глаголом, от лица героини: «Обнять его», а не «Она обняла его».
- Никакой разметки, эмодзи и кавычек-«ёлочек» внутри реплик — только живой русский текст.
  Прямую речь внутри narration заключай в « ».
- Язык: русский, живой и современный. Героиня — «ты» (narration от второго лица).

--------------- СТРУКТУРА СЮЖЕТА (геймдизайн) ---------------
- Объём: 20–35 сцен, 8–12 точек выбора, 3 разных финала (минимум 2).
- Схема «ствол и ветки»: выборы ведут в разные сцены (s4a/s4b/s4c), которые через 1–2 сцены
  сходятся обратно в общую сцену. НЕ строй 3 полностью отдельных истории — строй ветвящийся ствол.
- КАЖДАЯ сцена достижима, тупиков без ending/next/choices быть не должно.
- Платные выборы (crystals): всего 4–6 на историю. Цена только 10, 12 или 15.
  Платный выбор ОБЯЗАН давать то, чего нет в бесплатном: отдельную эмоциональную сцену,
  важное признание, улику, +1 к шкале отношений, доступ к лучшему финалу.
  Платный выбор НИКОГДА не блокирует основной сюжет: без него история проходится полностью.
- Шкалы должны реально влиять минимум на 1 финал (через branch) и на 1–2 выбора (через requires).
- Пороги requires/branch проверяй арифметикой: посчитай МАКСИМУМ очков шкалы, который игрок
  физически может набрать к этой точке (по лучшему пути), и ставь порог ниже максимума,
  иначе выбор/финал недостижимы. Укажи эти максимумы в отчёте самопроверки.
- Ритм: каждые 2–4 сцены — выбор. Первый выбор — не позже второй сцены.
  Первый платный выбор — не раньше третьей точки выбора (дай игроку втянуться).
- Финалы должны заметно отличаться по смыслу и настроению, а не одной фразой.

--------------- КАРТИНКИ (ЧАСТЬ 2 ОТВЕТА) ---------------
После JSON дай таблицу: файл | тип | промпт.
- Пути файлов в таблице должны ТОЧНО совпадать с путями в JSON (cover, bg, image персонажей).
- Один и тот же фон можно переиспользовать в нескольких сценах — не плоди лишние файлы:
  обычно 5–8 фонов на историю.
- Промпты пиши по-английски. К КАЖДОМУ промпту в конце добавляй единый стиль (дословно):
  "soft romantic visual novel art, warm beige and muted earthy color palette, gentle diffused light,
  minimalist elegant composition, cinematic, no text, no watermark"
- Обложка (cover): вертикальная 2:3, героиня и ключевой персонаж/предмет истории, атмосферно, без текста.
- Фон (bg): вертикальный 9:16, ПУСТАЯ локация без людей, нижняя треть кадра спокойная (там будет текст).
- Персонаж (image): поясной портрет одного человека, прозрачный/однотонный фон, PNG;
  внешность каждого персонажа описывай одинаково во всех промптах, где он встречается.
- Если картинок для каких-то сцен не будет — bg оставь "", градиент обязателен в любом случае.

--------------- САМОПРОВЕРКА (ЧАСТЬ 3 ОТВЕТА) ---------------
Перед отправкой молча проверь и в отчёте подтверди цифрами:
1. JSON валиден: нет комментариев, нет запятых в конце объектов, все кавычки закрыты.
2. Сцен: N, точек выбора: N, платных выборов: N (цены только 10/12/15), финалов: N.
3. Каждый next / to / choices.next ведёт в существующую сцену. Каждая сцена достижима от start.
4. Максимум каждой шкалы stats по лучшему пути: шкала = число. Все пороги requires/branch ниже этих максимумов.
5. Все who и show есть в characters; все effect/requires — в stats.
6. Ни одна строка не длиннее 220 символов, ни один выбор — 60.

Теперь придумай историю и выдай ответ из трёх частей. Начни сразу с блока ```json.
```

## ▲ КОПИРОВАТЬ ДОСЮДА ▲

---

### Что делать с ответом ИИ

| Часть ответа ИИ | Куда деть |
|---|---|
| 1. JSON | Сохранить как `stores/N.json`, проверить `node tools/validate.mjs stores/N.json`, закоммитить |
| 2. Таблица картинок | Сгенерировать изображения, положить по путям из таблицы в `assets/`, закоммитить. Можно позже — без картинок работают градиенты |
| 3. Отчёт | Глазами сверить цифры: финалов ≥ 2, платных выборов 4–6, пороги достижимы |

Если валидатор ругается — не правь вручную: скопируй текст ошибок и отправь той же ИИ фразой: *«Исправь эти ошибки валидатора и перевыдай только JSON целиком»*.
