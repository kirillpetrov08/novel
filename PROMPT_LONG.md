# Промпт для генерации ДЛИННОГО романа (1–2 часа) в «Новеллу»

> Скопируй всё ниже разделителя в чат с ИИ-генератором, у которого есть доступ
> к репозиторию `novel`. Он сам придумает сюжет — здесь только формат, объём
> и правила. Эталон готовой длинной истории: `stores/12` («До конечной»).

---

Ты — автор-генератор интерактивных романтических новелл для приложения
«Новелла». Работай **полностью автономно**: не задавай вопросов, не жди
подтверждений. Твоя задача — создать **ОДИН длинный роман** в папке
`stores/N/`, где N — следующий свободный номер (посмотри список папок в
`stores/`). Сюжет, сеттинг и героев придумай сам. Перед выбором темы прочитай
`description` историй в `stores/1..N-1` и **не повторяй** их сеттинги и
профессии героев (уже заняты, в частности: маяк, гончарная, фотолаборатория,
ночной музей, винодельня, театр, аэродром, траулер, цирк, радиостанция, поезд).

## Объём и структура (это длинный формат!)

- Поле `"format": "long"` — обязательно (попадает в секцию «Длинные романы»).
- **140–170 сцен**, **480–560 реплик** суммарно (строк во всех `lines`).
- `"estimatedMinutes"`: посчитай как `число реплик / 7.5`, округли (получится
  примерно 65–90). Не ставь меньше 60.
- **6 глав** примерно по 25 сцен. ID сцен: префикс главы `a,b,c,d,e,f` +
  номер (`a01`, `a02`…); ветки-ответы выборов — суффиксы (`a03a`, `a03b`).
- Драматургия: гл.1 знакомство и завязка тайны/проблемы; гл.2 сближение;
  гл.3 «вылазка» и личные признания; гл.4 кризис/испытание стихией или
  обстоятельствами; гл.5 развязка тайны + главный моральный выбор;
  гл.6 финал на «точке невозврата». В каждой главе — 5–7 точек выбора.
- Выборов всего: **30–38 точек**, из них **ровно 10–12 платных** и каждый
  платный — **ровно 5 кристаллов** (`"crystals": 5`), ни больше ни меньше.
- **3 финала**. В предпоследней сцене — `branch` по характеристикам
  (формат ниже) + `next` на запасной финал.
- Характеристики (ровно эти три, объект, НЕ массив):
  `"stats": {"desire": {"label": "Желание", "icon": "♡"}, "trust": {"label": "Доверие", "icon": "◌"}, "resolve": {"label": "Решимость", "icon": "✦"}}`
- **Баланс финалов (проверь BFS-скриптом, напиши его сам):**
  - финал «Доверие» достижим **полностью бесплатно**;
  - финал «Решимость/Дорога» достижим бесплатно;
  - порог финала «Желание» = (максимум `desire` на бесплатном пути) + 1,
    т.е. нужен хотя бы один платный выбор;
  - все сцены и все финалы достижимы, тупиков нет.
- Персонажи: 3–4 человека, 12–16 состояний-эмоций суммарно. В `characters`
  **каждое состояние — отдельный ключ** (`heroine`, `heroine_smile`, …) со
  своими `name` и `color`. В репликах `who` — только базовый ключ
  (`heroine`, `hero`, `friend`, `director`), в `show` — ключ состояния.
  На экране одновременно не больше 3 персонажей.

## Формат сцены (строго)

```json
"a01": {
  "bg": "images/bg-<slug>.jpg",
  "bgGradient": ["#D8C7A8", "#6E5B49"],
  "show": ["heroine"],
  "lines": [
    {"type": "narration", "text": "…"},
    {"type": "dialogue", "who": "heroine", "text": "…"},
    {"type": "thought", "text": "…"}
  ],
  "next": "a02"
}
```

- У сцены ровно один исход: `choices` **или** `next` **или** `branch`
  (+`next` как запасной) **или** `ending`.
- Выбор: `{"text": "…", "next": "…", "crystals": 5, "requires": {"trust": 2}, "effect": {"desire": 1, "trust": 1}}`
  (`crystals`/`requires`/`effect` необязательны; `requires` и `effect` —
  объекты `{"статистика": число}`).
- Branch: `"branch": [{"if": {"stat": "desire", "gte": 9}, "to": "ending_x"}]`
  + `"next": "ending_fallback"`. Другого формата ветвления нет!
- Финал: `"ending": {"title": "…", "text": "2–4 предложения", "badge": "Доверие"}`.
- Одна реплика — **не длиннее 240 символов** (иначе переполнит экран).
- Обязательные поля истории: `id` (латиницей, кебаб), `title`, `subtitle`
  (1 предложение), `description` (абзац), `genre: "Романтика · Чувственная драма"`,
  `tags` (4–5), `format`, `estimatedMinutes`, `characters`, `stats`,
  `start`, `scenes`. Поля `author` НЕ существует. Тега «18+» НЕ ставить.
- Герои взрослые (25+), всё по взаимному согласию, откровенные сцены —
  только намёком и затемнением (fade-to-black). Изображения — все одеты.

## Картинки (21 штука) и `art-prompts.json`

Файл `stores/N/art-prompts.json` — объект
`{"story": "<id>", "style": "…", "images": […24 или 21 позиций…], "sceneBackgrounds": {"<сцена>": "images/bg-….jpg"}}`
(для длинной истории достаточно 21). Заполни `sceneBackgrounds` для всех сцен
И одновременно проставь тот же `bg` прямо в сценах.

- `cover.jpg` — вертикальная обложка, пары героев, без текста.
- 6 фонов `images/bg-*.jpg` под ключевые локации глав.
- 14 портретов `images/<ключ_состояния>.png`: по пояс, однотонный светло-
  бежевый фон `#EADFCB`, живописная масляная стилистика, тёплая бежевая
  палитра. В промптах портретов ** дословно повторяй** внешность персонажа
  (возраст, волосы, одежда) и меняй только эмоцию.
- Генерируй **по одной картинке**, дожидаясь результата; `offer_options=false`.
- Лимит платформы: **не больше 10 генераций подряд**. Генерируй пачками ≤10,
  после каждой пачки записывай прогресс в `stores/N/PROGRESS.md`
  (что готово, что осталось) и коммить. Если ход прервался — при следующем
  запуске сначала прочитай `PROGRESS.md` и ПРОДОЛЖАЙ с места остановки,
  не переделывая готовое.

## Самопроверка перед финишем (обязательно)

1. `node tools/validate.mjs stores` — ноль ошибок по твоей истории.
2. Свой BFS по сценам со статами: все сцены и финалы достижимы; баланс
   финалов — как выше.
3. Все файлы из `art-prompts.json` реально лежат в папке; каждый `show`
   ссылается на существующий ключ персонажа; каждый `bg` — на существующий фон.
4. Коммить на свою ветку по этапам (текст → арт пачками → финал).
5. В самом конце напиши пользователю: ветку и список SHA коммитов — по ним
   историю примут в приложение.

Начинай: сначала план глав и скелет сцен в `PROGRESS.md`, затем текст по
главам, затем картинки. Не останавливайся на полпути и не сокращай объём.
