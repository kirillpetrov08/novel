# Новелла — интерактивные истории (Android-приложение для RuStore)

Библиотека визуальных новелл в духе «Клуба Романтики»: ветвящийся сюжет, выборы за кристаллы, несколько финалов, реферальные бонусы. Это **не сайт**: готовый продукт — Android-приложение (AAB для RuStore / APK для теста), в которое истории вшиты и работают офлайн. Веб-версия осталась как инструмент разработки и проверки историй.

## Как устроено

- **Ядро**: HTML/CSS/JavaScript без фреймворков (`index.html`, `css/`, `js/`) — системные шрифты, ноль подзагрузок.
- **Android**: [Capacitor](https://capacitorjs.com) (`android/`, package `ru.novella.reader`, minSdk 24, targetSdk 36).
- **Истории**: одна история = одна папка `stores/N/` → `story.json` + фото рядом. При сборке `tools/prepare-www.mjs` валидирует их и вшивает в приложение.
- **Сборка**: GitHub Actions (`.github/workflows/build-android.yml`) при каждом коммите в `main` собирает **тестовый APK** и **AAB для RuStore**, versionCode растёт автоматически. Подпись — из секретов репозитория (ключ не в Git!). Инструкция: [`RUSTORE.md`](RUSTORE.md).

## Быстрый старт

```bash
npm install            # один раз
npm run validate       # проверить все истории в stores/
npm run build:android  # собрать www/ и синхронизировать Android-проект
npm run dev            # веб-режим проверки: http://localhost:8000
```

## Как добавить историю

1. Получи `story.json` и картинки от ИИ по промпту из [`PROMPT_FOR_AI.md`](PROMPT_FOR_AI.md) (сюжет придумывает она).
2. Создай папку `stores/N/` (следующий номер подряд), положи в неё `story.json`, `cover.jpg`, `images/…`.
3. `npm run validate` → закоммить папку в `main`.
4. Скачай готовый AAB из GitHub Actions → загрузи в RuStore как новую версию.

Подробно: [`stores/README.md`](stores/README.md), [`STORY_FORMAT.md`](STORY_FORMAT.md), публикация и обновления: [`RUSTORE.md`](RUSTORE.md).

## Что умеет приложение

- **Библиотека** с прогрессом и счётчиком открытых финалов; **плеер** с фонами и персонажами, печатной машинкой, журналом, автосейвом на каждой реплике; аппаратная кнопка «Назад» на Android.
- **Ветвления**: шкалы характеристик от выборов открывают особые реплики и разные финалы.
- **Кристаллы ◆** (все цифры в `js/config.js`): старт +20, реклама +5, ежедневный бонус +5, прохождение +20, новый финал +10. Покупок за деньги нет — RuStore Billing не нужен.
- **Рефералы**: код `NV-…` и ссылка, +15 ◆ новичку, +20 ◆ пригласившему. Серверный апгрейд между устройствами описан в [`REFERRAL_BACKEND.md`](REFERRAL_BACKEND.md).
- **Реклама Яндекса** подключена нативно (Yandex Mobile Ads SDK, блоки `R-M-20304990-*`): вознаграждаемая — магазин и удвоение награды за финал ×2; межстраничная — между новеллами и после финала; нативная — карточка в библиотеке. Детали и активация — `RUSTORE.md`, раздел «Реклама».

## Структура

```
index.html, css/, js/     — ядро приложения (дизайн — строгая бежевая палитра)
stores/                   — СЮДА коммитятся истории: 1/ (story.json + фото), 2/, …
android/                  — Android-проект Capacitor (собирается в APK/AAB)
.github/workflows/        — автосборка APK+AAB в GitHub Actions
tools/validate.mjs        — проверка историй (npm run validate)
tools/prepare-www.mjs     — вшивание историй и сборка www/ для Android
tools/make-icons.py       — иконки и сплеш (Pillow)
rustore/icon-512.png      — иконка для карточки RuStore
privacy-policy.md         — готовая политика конфиденциальности (заполни поля в скобках)
PROMPT_FOR_AI.md          — промпт для ИИ-генератора историй и картинок
STORY_FORMAT.md           — техническая справка по формату story.json
RUSTORE.md                — публикация в RuStore: ключ подписи, CI, карточка, обновления
REFERRAL_BACKEND.md       — настоящие реклама/рефералы между устройствами (следующий этап)
```
