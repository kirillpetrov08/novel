ИМПОРТДОБАВИТЬ ИСТОРИЮ ВРУЧНУЮ

Основной способ — папка истории в репозитории: stores/1/ (сюжет story.json + фото рядом), stores/2/, … Истории вшиваются в приложение при сборке. Здесь можно быстро проверить историю до коммита: перетащи story.json, выбери файл или вставь JSON текстом.

Правила формата

• Одна папка = одна история: сюжет и фото вместе.
• В репозитории: stores/1/story.json, stores/2/story.json… — номера папок подряд, без пропусков. Пути к фото в story.json — относительные (cover.jpg, images/bg-01.jpg).
• Полная схема и шаблон: папка stores/_template/ и STORY_FORMAT.md.
• Проверка перед коммитом: npm run validate
• Битый файл не ломает приложение — ошибка покажется в библиотеке.
